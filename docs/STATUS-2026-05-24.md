## 8. Known gotchas

- **`@tauri-apps/plugin-shell` import**: may need fallback `invoke("plugin:shell|open", { path })` if named export doesn't resolve.
- **Cargo mirror**: `.cargo/config.toml` is currently DIRECT crates.io (no mirror). SJTUG worked once but flaps. If a new dep fails, retry with `replace-with = "sjtug"` in `.cargo/config.toml`.
- **pdf_path guard breaks old tests**: any test creating `Paper { pdf_path: None, ... }` will fail. Fixtures in `tests::sample` and `tags::tests::paper` already updated to `Some("/tmp/test-..pdf")`.
- **frontendDist for cargo check**: `pnpm build` must succeed once before `cargo check` will pass — Tauri's `generate_context!` macro validates `../dist` exists.
- **Existing DB rows with NULL pdf_path**: were inserted before the guard; show as "无 PDF" in Library row but cannot be re-touched without manual SQL.
